# Descripción del Repositorio / Repository Description

Este documento contiene las descripciones recomendadas para usar en la sección "About" del repositorio de GitHub.

## Para la Sección "About" de GitHub

### Versión en Inglés (Recomendada para audiencia internacional)
```
Cybersecurity Education: SQL Injection Detection & ISO 27001 Incident Reporting. Interactive learning project teaching students to identify SQL injection vulnerabilities using DVWA and create professional incident reports following ISO 27001 standards.
```

**Tecnologías clave:** Linux, VirtualBox, DVWA, SQL Injection, ISO 27001, Cybersecurity, Incident Management

### Versión en Español
```
Educación en Ciberseguridad: Detección de Inyección SQL e Informes de Incidentes ISO 27001. Proyecto educativo interactivo que enseña a estudiantes a identificar vulnerabilidades de inyección SQL usando DVWA y crear informes profesionales siguiendo estándares ISO 27001.
```

**Tecnologías clave:** Linux, VirtualBox, DVWA, Inyección SQL, ISO 27001, Ciberseguridad, Gestión de Incidentes

## Cómo usar estas descripciones

### 1. Descripción del Repositorio en GitHub
Para actualizar la sección "About" en GitHub:
1. Ve a la página principal de tu repositorio en GitHub
2. Haz clic en el ícono de engranaje (⚙️) junto a "About" en la barra lateral derecha
3. Copia y pega la descripción elegida en el campo "Description"
4. Opcionalmente, agrega los siguientes topics: `cybersecurity`, `sql-injection`, `iso-27001`, `dvwa`, `education`, `security-training`

### 2. Descripción para Portafolios y CVs
**Versión corta para desarrolladores:**
"Proyecto educativo de ciberseguridad enfocado en detección de vulnerabilidades SQL injection y elaboración de informes de incidentes según ISO 27001."

**Versión para reclutadores:**
"Proyecto práctico de ciberseguridad que demuestra habilidades en identificación de vulnerabilidades, pruebas de penetración y documentación profesional de incidentes de seguridad según estándares internacionales."

## Valor del Proyecto

Este repositorio demuestra competencias en:
- **Ciberseguridad práctica**: Identificación y explotación de vulnerabilidades SQL injection
- **Gestión de incidentes**: Creación de reportes profesionales según ISO 27001
- **Tecnologías de virtualización**: Configuración y manejo de entornos virtuales
- **Documentación técnica**: Elaboración de informes estructurados y profesionales
- **Mejores prácticas de seguridad**: Comprensión de estándares internacionales

## Audiencia Objetivo
- Estudiantes de ciberseguridad
- Profesionales de IT interesados en seguridad
- Reclutadores evaluando competencias técnicas
- Instructores de ciberseguridad
